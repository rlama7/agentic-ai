# Module 3: Functions as Tools

A local Python implementation of the Tool Use exercise
from Andrew Ng's Agentic AI course by DeepLearning.AI.

## Learning Objectives

- Define Python functions as LLM tools.
- Understand automatic tool calling with AISuite.
- Implement manual tool execution.
- Coordinate multiple tools in an agentic workflow.

## Tech Stack

- Python 3.11
- AISuite
- OpenAI API
- pytest

## Setup

1. Create and activate a Python virtual environment.
2. Install dependencies using `requirements.txt`.
3. Configure `.env` with `OPENAI_API_KEY`.
4. Run the application using `python -m src.main`.
