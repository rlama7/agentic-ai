# Agentic AI

A collection of experiments and applications exploring agentic AI
systems and their integration with modern frontend architecture.

The repository focuses on bridging:

- Python-based AI agents
- LLM APIs and tool calling
- Retrieval and structured outputs
- FastAPI backend services
- React + TypeScript applications
- Streaming AI interfaces
- Production frontend architecture

## Technologies

### AI / Backend

- Python
- FastAPI
- OpenAI
- Anthropic
- AISuite
- Tavily
- Pydantic

### Frontend

- React
- TypeScript
- Vite
- TanStack Query
- Zustand
- Vitest
- React Testing Library
